# Whisper base speech model (faster-whisper format), mirrored

An unchanged copy of the `Systran/faster-whisper-base` model files, hosted as a GitHub release so that sandboxes that can reach GitHub but not Hugging Face can run speech-to-text.

- Original model: OpenAI Whisper (https://github.com/openai/whisper), MIT License.
- Converted to CTranslate2 format by Systran: https://huggingface.co/Systran/faster-whisper-base (MIT License).
- Use with faster-whisper: https://github.com/SYSTRAN/faster-whisper

`model.bin` SHA-256: d01c3014881c9c6f3133c182f3d2887eb6ca1c789a7538c5c007196857a0a6a9 (matches the Hugging Face original).
